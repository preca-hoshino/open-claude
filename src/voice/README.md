# src/voice — 语音模式控制模块

> 项目总览：参见 [README.md](../../README.md)
> 
> 相关模块：[`src/assistant/README.md`](../assistant/README.md)

## 简介

Voice 模块负责处理与语音交互相关的状态与逻辑。当前主要提供判断是否启用语音交互模式的检测与控制功能。

## 目录结构

```text
voice/
├── voiceModeEnabled.ts              # 判断是否允许语音交互的功能实现
└── __test__/                        # 测试目录
    └── ...
```

## 实现逻辑

### 权限与配置检测
`voiceModeEnabled.ts` 通过综合研判系统的授权状态（Auth）以及特性开关（如 Growthbook flags 等环境配置），动态返回当前用户或当前构建版是否被允许启用语音模式。

### 状态分离与防渗透
将复杂的规则判定抽离在此，使得上层调度逻辑可以直接调用单个判断函数，而不必关心底层繁杂的开关逻辑，保障了架构的纯净。

## 新增 / 重构 / 删除向导

### 新增
- 添加新的允许或禁用维度（例如受限网络环境校验）时，在判定链条中串接对应逻辑。
- 在 `__test__` 中必须补充相关维度缺失时的拦截断言。

### 重构
- 任何判定逻辑的调整都必须保证默认退化为 `false`（安全失败策略），以防止未授权情况下激活不稳定的语音特性。

### 删除
- 如果要下线语音模式，除了删除此判定逻辑，还需追溯调用方，将对应的入口入口彻底屏蔽。
