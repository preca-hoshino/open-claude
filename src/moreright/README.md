## 简介

MoreRight 模块主要封装了终端与 UI 界面中用于控制显示与交互样式的自定义 React Hook 或组件。它用于在现有界面中注入特定的增强视图交互逻辑（目前主要面向内部使用，外部开源构建中提供存根兼容）。

## 目录结构

```text
moreright/
├── useMoreRight.tsx                 # 自定义 Hook：管理界面相关的增强逻辑与侧边状态（存根）
└── __test__/                        # 测试目录
    └── ...
```

## 实现逻辑

### Hook 接口契约
`useMoreRight` 提供了包含 `onBeforeQuery`、`onTurnComplete` 及 `render` 的声明式接口。此设计允许外部组件通过依赖注入的形式，将额外的数据流拦截和渲染逻辑安全地嵌入。

### 内部与开源版本拆分
由于涉及未开源的专有交互或界面资产，当前开源版本中的实现被替换为占位符存根（Stub），返回始终允许通行的 Promise 和空的渲染节点，以维护项目在外部编译环境下的类型完整性。

## 新增 / 重构 / 删除向导

### 新增
- 扩充 `useMoreRight` 的接收参数或返回接口时，必须注意泛型及 `any` 类型的收敛，避免类型泄露。

### 重构
- 任何接口结构的变更均需考虑上层消费者（如 CLI 的主界面框架）的兼容性，确保两端的代码能够同步调整。

### 删除
- 彻底移除此增强组件及其引用时，应当从相关的 UI 入口（如 `main.tsx` 或组件树高层）自顶向下逐步清理注入依赖。
