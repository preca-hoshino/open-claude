# src/entrypoints — 系统启动引导与运行模式路由模块

> 参见 [README.md](../../README.md)

## 简介

本模块负责处理应用程序在不同运行模式下的启动引导与依赖初始化。其核心机制是通过动态的模块导入与特化的快速路径（Fast-path）路由，在尽量延迟加载庞大依赖树的前提下，将控制权移交给指定的子系统或应用主循环。本模块作为整个系统生命周期的总入口，直接服务于底层操作系统调用和外部协议请求（例如模型上下文协议），为上层核心业务搭建并隔离运行时环境。

## 目录结构

```text
├── agentSdkTypes.ts         # Agent SDK 公共 API 接口与类型定义入口
├── cli.tsx                  # 命令行主入口程序，负责处理快速路径路由并启动系统
├── dev-cli.tsx              # 注入开发时全局变量的 CLI 包装器
├── dev-mcp.ts               # 注入开发时全局变量的 MCP 服务器包装器
├── init.ts                  # 全局初始化引导程序，负责配置挂载、遥测初始化与网络层代理设置
├── mcp.ts                   # MCP 服务端实现，对外暴露内部工具
├── sandboxTypes.ts          # 沙箱配置的 Zod 校验模式与类型定义
└── sdk/                     # SDK 核心类型的内部定义模块
```

## 实现逻辑

### 1. 命令行启动优化

`cli.tsx` 采用延迟加载（Lazy Loading）策略，在解析参数后，针对版本号查询、远程控制、后台守护进程的特定子命令或标志提供快速执行路径。此机制避免了多余的模块计算与界面渲染开销。对于需要全量运行的流程，程序会在委托给主模块之前启动分析器（Startup Profiler）以追踪启动性能。

### 2. 全局环境初始化

`init.ts` 是复杂流程的初始化总线。程序负责配置系统激活、安全环境变量挂载、应用状态填充、互相认证传输层安全（mTLS）设置以及全局网络代理挂载。该机制确保所有底层网络请求与遥测体系均在受信任的安全上下文中运行，并向系统级清理钩子注册了进程终止时的资源释放函数。

### 3. 服务端接入与接口封装

`mcp.ts` 构建并启动了模型上下文协议（Model Context Protocol）服务器，将内部工具映射为可被外部客户端调用的独立服务。同时，`agentSdkTypes.ts` 集中提供了对外扩展系统的类型签名与函数声明，涵盖会话分叉、工具调用和远程控制机制的底层能力。

### 4. 沙箱类型系统

`sandboxTypes.ts` 集中定义了文件系统与网络维度的沙箱配置结构，利用 Zod 提供严格的运行时校验边界，确保环境变量与系统设置的注入具有确定的类型安全性。

## 新增 / 重构 / 删除向导

### 新增

添加启动模式或快速路径标志时，请在 `cli.tsx` 中写入路由逻辑前，确保所有必需的依赖全部通过动态 `await import()` 加载以防止拖慢系统整体启动时间；加入全局初始化逻辑时，请评估其影响范围并补充到 `init.ts` 中，务必处理好对应资源的优雅关闭钩子。

### 重构

修改入口点或全局初始化流程时，请保持现存命令行标志与环境变量的向后兼容性；由于 `cli.tsx` 和 `init.ts` 在环境隔离和沙箱应用之前运行，若包含安全失败（Fail-safe）或权限敞口策略，请显式声明安全意图，保证网络代理、遥测机制或外围服务的非致命失败不会阻塞核心业务的启动。

### 删除

下线单一入口或启动模式时，请在对应的入口路由处切断执行逻辑，并在 `init.ts` 中同步移除关联的初始化挂载代码；移除废弃的公共接口时，请增加 `@deprecated` 标记进行一整个版本周期的废弃警告后再执行物理代码清理，并通知所有上游调用方修改依赖。
