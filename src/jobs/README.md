## 简介

Jobs 模块主要用于管理和调度后台作业。它包含将各种异步任务进行分类、排队和分发的逻辑，确保各项系统任务和异步流程高效、有序地运行。当前以提供分类存根机制为主。

## 目录结构

```text
jobs/
├── classifier.ts                    # 任务分类器，负责鉴别并分配任务类型（存根）
└── __test__/                        # 测试目录
    └── ...
```

## 实现逻辑

### 任务类型推断与分类
`classifier.ts` 中的 `classifyAndWriteState` 等接口承担了任务类别的判断职责。它会解析助手消息上下文，对任务执行状态进行归档，或推断需要调度的子作业类型。

### 后台状态同步
基于分类结果，它负责协调和同步特定的状态文件或环境配置（如 `_jobDir` 写入），以支持分离架构或守护进程环境下的独立执行流。

## 新增 / 重构 / 删除向导

### 新增
- 增加新类型的后台 Job 时，需在 `classifier.ts` 的接口签名中预留支持字段，以保证类型约束的向下兼容。
- 必须在其 `__test__` 目录下补充对应的分类规则断言，保证鉴别逻辑的一致性。

### 重构
- 更改任务分类机制时，需要核实上游调用方（如消息解析队列）的传入数据结构是否会受到阻断影响。

### 删除
- 删除分类器或某些特定任务类型的支持前，务必全量评估历史任务快照，避免出现因缺少匹配类型而导致的幽灵任务堵塞。
