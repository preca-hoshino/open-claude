# src/stubs — 外部依赖存根模块

> 项目总览：参见 [README.md](../../README.md)
> 
> 相关模块：[`src/plugins/README.md`](../plugins/README.md)

## 简介

Stubs 模块用于存放与系统外部环境或依赖交互的桩代码（Stub）和存根。特别是在 MCP (Model Context Protocol) 扩展以及跨环境调用场景中提供测试与交互桩，确保核心逻辑在缺少特定插件时不会崩溃。

## 目录结构

```text
stubs/
└── ant/                             # 专有生态系统预留桩（例如 Claude for Chrome 等扩展）
    └── __test__/                    # 测试目录
```

## 实现逻辑

### 隔离外部协议
通过提供例如 `createClaudeForChromeMcpServer` 这样的工厂桩函数，屏蔽了主调方对非开源扩展协议的具体依赖。调用这些桩时会显式抛出未实现的异常（提示不可用）。

### 预置空资产
定义了如 `BROWSER_TOOLS` 的空数组占位符，保证解析器或加载器遇到对应的环境变量或加载需求时能优雅失败。

## 新增 / 重构 / 删除向导

### 新增
- 添加其它平台/插件存根时，应严格对齐私有插件项目的类型定义，确保存根接口的正确性。

### 重构
- 如果私有插件侧对某些方法进行了重构，务必同步更新本存根模块的接口定义以防止类型失效。

### 删除
- 清除某个存根模块前，需要全局搜索并解除系统各处对该存根注入函数的调用。
