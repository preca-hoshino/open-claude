# src/buddy — 助手与彩蛋模块

> 项目总览：参见 [README.md](../../README.md)
> 
> 相关模块：[`src/state/README.md`](../state/README.md)（该模块的状态订阅与彩蛋动作具有强关联）

## 简介

本模块负责实现 Open-Claude 中独具特色的 Companion（虚拟助手精灵）功能。通过确定性伪随机生成机制与基于文本 ASCII 的极简动画引擎，该模块为用户提供趣味性的视觉反馈。作为纯前端的视图组件层，它主要寄宿于界面的右下角，服务于提升用户交互体验。

## 目录结构

```text
buddy/
├── companion.ts              # 核心配置，基于种子生成精灵外观属性
├── CompanionSprite.tsx       # 核心渲染，驱动动画与帧流转的 React 组件
├── prompt.ts                 # 注入给大模型的提示词约束，避免越俎代庖
├── sprites.ts                # 视觉资源，定义各物种的 ASCII 字符阵列和动画序列
├── types.ts                  # 精灵类型的接口与枚举定义
└── useBuddyNotification.tsx  # 通知调度，负责引导彩蛋及匹配用户输入触发
```

## 实现逻辑

### 1. 精灵生成与数据结构 (`companion.ts` & `types.ts`)
Companion 的属性生成机制采用了确定性伪随机算法（PRNG），确保同一用户获得的精灵形态稳定。
- **Mulberry32 生成**：基于哈希种子，通过 `mulberry32` 生成序列。
- **骨架与状态合成**：生成的精灵包含种类、稀有度等骨架（Bones），随后与持久化读取的灵魂状态（如名字）进行混合。

### 2. 视觉渲染与动画引擎 (`sprites.ts` & `CompanionSprite.tsx`)
这是一个高度精简的基于文本 ASCII 的动画引擎。
- **动作序列控制**：`sprites.ts` 内置字符画数组，通过替换占位符渲染不同状态。
- **React 定时器驱动**：`CompanionSprite.tsx` 内置周期性计时器驱动状态机流转，响应交互或渲染后端气泡。

### 3. 模型侧提示词约束 (`prompt.ts`)
为防止大模型混淆自身与 Companion 身份，系统会在特定轮次附加限制。
- **角色隔离**：强制通过系统提示告知大模型其身份边界，把短回复的权利留给动画气泡。

### 4. 触发与通知流 (`useBuddyNotification.tsx`)
- **彩蛋引导**：内置基于日期的激活逻辑以发送引导消息。
- **正则匹配指令**：解析输入框文本驱动隐藏逻辑。

## 新增 / 重构 / 删除向导

### 新增
- 在 `sprites.ts` 中增加任何物种时，必须严格遵守 12 字符宽度与 5 行高度的网格约束。
- 同步在 `types.ts` 中注册新增种类的枚举项。

### 重构
- 调整随机池子时，必须考虑向后兼容性避免现有精灵形态突变。
- 解耦状态订阅，严禁在此引入高频更新字段导致全局帧率下降。

### 删除
- 淘汰彩蛋时，必须清理附着于大模型上下文的 `prompt.ts` 注入逻辑。
- 追溯所有主界面的挂载点并予以拔除。
