# src/buddy — 伴侣系统与终端精灵模块
> 参见 [README.md](../../README.md)
> 本模块与 [src/state](../state/README.md) 具有实质调用关系，依赖应用层状态管理来读取伴侣互动状态与派发操作反馈。

## 简介
本模块负责在命令行交互体系中构建并驱动一个独立人格化的终端伴侣（Companion）。本模块通过内置确定性哈希算法及时间帧滴答驱动机制，实现伴侣骨架的稳定生成及 ASCII 字符动画效果。本模块服务于应用界面的展示层，用于在不破坏终端主要流程的情况下提供伴侣侧边视觉反馈。

## 目录结构
```text
src/buddy/
├── companion.ts             # 基于用户标识散列的伪随机伴侣属性计算规则
├── CompanionSprite.tsx      # 伴侣精灵终端界面的渲染及动画状态机控制流
├── prompt.ts                # 面向大语言模型的伴侣身份隔离前置指令构建器
├── sprites.ts               # 物种专属多帧 ASCII 字符画的字典存储与序列截取逻辑
├── types.ts                 # 伴侣系统运行依赖的核心参数类型与常数字典定义
└── useBuddyNotification.tsx # 特定时效窗口内的触发提示与彩蛋预告通知下发钩子
```

## 实现逻辑
### 1. 伴侣属性演算与存储解耦
入口锚点：`companion.ts`。本机制利用预设的伪随机数生成器（Pseudo-Random Number Generator）处理用户唯一标识散列，以此确定性地运算出伴侣的骨架数值（包含物种、装饰及基础属性）。落盘至持久化配置文件时仅保存脱离特定骨架的灵魂属性（涵盖姓名、性格偏好与初次孵化时间点）。拆分数值与灵魂能够防止后续版本修改物种字典导致已有用户的终端存量数据遭到损坏。

### 2. 精灵界面渲染与布局折叠
入口锚点：`CompanionSprite.tsx`。系统通过生命周期定时器触发毫秒级的全量状态滴答（Tick），并按时间索引从 `sprites.ts` 内抽取相应物种的具体动作帧（Frame）投射至界面视图。为了应对不同宽度的命令行容器，本模块嵌入了显式的状态折叠安全边界；当计算可用列宽不满足展示阈值时，组件会强制回退为极简的单行字符模式，借此保障主线界面的核心代码浏览功能不受挤占。

### 3. 模型侧视角边界管控
入口锚点：`prompt.ts`。在构建发往大语言模型的交互上下文流之前，本机制动态插入包含特定身份宣告的系统提示词（System Prompt）。该附件通过明示伴侣作为独立观察者存在的规则，约束主干模型规避替身回复。实施该操作在会话内容结构中分离了模型主体任务执行区与伴侣彩蛋反馈区。

### 4. 互动线索通知与拦截分发
入口锚点：`useBuddyNotification.tsx`。系统在应用程序冷启动阶段，探测特定节假日时间范围窗口及用户配置中的伴侣存在状态。若匹配到彩蛋触发条件，则调用全局通知派发器在界面顶部注入临时预告提示，并在用户键入指令时提供正则表达式的触发位置截取能力，以保障功能曝光与入口触达。

## 新增 / 重构 / 删除向导
### 新增
扩展新伴侣物种或特征时，请前往 `types.ts` 中的常量列表插入新枚举成员；其次在 `sprites.ts` 的字典内填补对应动态切换的 ASCII 字符阵列组合；务必确保每行字符画严格维持五行高与十二列宽的硬性设计规范，并保留头部槽位（Line 0）以兼容帽子的叠加。

### 重构
调整属性分布池或改写时间循环逻辑时，禁止篡改原本基于用户散列运算的确定性计算法则，防止老用户升级后遭遇伴侣外貌骤变；如需补充新的悬浮图层特性，必须在 `CompanionSprite.tsx` 内部设置安全失败（Fail-safe）约束规则，在极窄界面强行抹除所有绝对定位图层以防引起终端光标计算崩溃。

### 删除
执行功能移除流程时，清除本模块目录下的所有代码文件；定位至 `src/utils/config.ts` 抹除对应的伴侣全局配置文件声明属性；全局搜索并切断 `useBuddyNotification` 与 `CompanionSprite` 的引用点，追溯并屏蔽系统布局组件中向此模块发出的所有方法调用。
