# src/cli — 命令行接口与 SDK 通信传输模块

> 参见 [README.md](../../README.md)
> 供 [src/main.tsx](../main.tsx) 作为所有命令行子命令和无头模式的调用入口。

## 简介

本模块负责解析与执行非交互式命令行指令（涵盖后台任务、MCP 管理及插件安装），并提供供无头（Headless）模式与外部 SDK 通信的底层传输适配。其核心机制包括基于流的结构化输入输出处理、多种网络传输协议封装，以及隔离于主视图的命令行子逻辑分发。本模块服务于应用主入口层，支撑远程控制与自动化构建环境。

## 目录结构

```text
src/cli/
├── bg.ts                 # 后台进程指令处理函数存根
├── exit.ts               # 命令行退出助手，统一管理成功或异常终止进程的逻辑
├── ndjsonSafeStringify.ts # NDJSON 安全序列化工具，转义行分隔符防止流切分截断
├── print.ts              # 无头模式主循环，协调结构化通信流与脱机状态下的代理执行
├── remoteIO.ts           # 远程双向通信实现，管理网络协议下的流式读写与心跳维持
├── rollback.ts           # 版本回退指令处理函数存根
├── structuredIO.ts       # 结构化标准流封装，负责解析控制消息并处理异步权限请求
├── up.ts                 # 启动指令处理函数存根
├── update.ts             # 自动更新指令处理逻辑，包含安装环境检测与包管理器适配
├── handlers/             # 命令行子命令处理器集合（封装鉴权、插件及工具管理逻辑）
└── transports/           # 远程网络传输协议实现库（提供 WebSocket 与 SSE 客户端适配）
```

## 实现逻辑

### 1. 结构化 I/O 与协议解析
核心入口位于 `structuredIO.ts` 与 `remoteIO.ts`。`StructuredIO` 类接管输入输出数据流（Stream），按行读取并解析符合协议的 JSON 消息；其内部维护请求队列以管理异步权限请求与命令回调，当外部客户端发起 `can_use_tool` 控制指令时将其拦截并派发到权限模型。`RemoteIO` 继承自该类，将底层读写桥接至真实的 `Transport` 实例，提供会话令牌（Token）的鉴权注入与空闲连接的心跳维持。

### 2. 无头模式代理主循环
执行逻辑实现在 `print.ts` 的 `runHeadless` 函数中。该函数绕过交互式控制台 UI，直接连接结构化通信流与应用状态机，负责会话状态恢复、插件静默安装、生命周期钩子派发及沙盒环境初始化。它持续消费指令流，将有效消息推入全局调度队列交由底层系统处理，从而实现脱离终端界面的完全自动化代理运行。

### 3. 子命令路由分发
模块中的 `handlers/` 子目录及 `update.ts` 封装了独立子命令的执行链路。所有处理器均使用 `exit.ts` 提供的 `cliError` 与 `cliOk` 助手安全地输出信息并终止进程。各处理函数独立执行特定领域逻辑，完成操作后即刻退出进程，确保外部路由调度器可直接分发并获得确定性的执行结果。

### 4. 传输协议层适配
通过 `transports/` 目录构建，模块屏蔽了底层的网络架构差异。接口抽象提供 WebSocket 实时双向长连接及 SSE（Server-Sent Events）单向流机制，并额外封装了专用的客户端支持后台状态同步机制。建连逻辑中统合了环境变量校验与重试重连策略，确保在网络抖动场景下底层会话数据传输的高可用性。

## 新增 / 重构 / 删除向导

### 新增
若需增添命令行子指令，请在 `handlers/` 目录下创建对应的处理文件并暴露入口函数，并在主路由中注册映射；若需支持新的控制流协议，请在 `structuredIO.ts` 中解析并扩展校验模式（Schema）。

### 重构
若重构底层协议序列化工具，请确保兼容既有协议标准（必须正确处理 `U+2028` 特殊行分隔符）以防止消息截断；本模块在沙盒初始化与网络通信建连异常时执行安全失败（Fail-safe）策略直接阻断进程，重构权限拦截或网络配置链路时必须严格维持此安全意图，防止产生故障敞口。

### 删除
在下线旧的子命令处理函数或弃用某类传输协议时，请确认移除所有关联的解析逻辑及环境检测变量，并强制要求追溯并屏蔽所有外部工作流与调用方的请求入口。
