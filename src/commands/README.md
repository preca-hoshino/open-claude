# src/commands — 本地命令与斜杠命令实现模块
> 参见 [README.md](../../README.md)

## 简介
本模块负责定义并实现系统中所有的内置命令行接口命令与斜杠命令（包含 `/init` 与 `/commit`）。它将终端输入映射为具体的执行逻辑、系统级提示词（Prompt）组装或基于 JSX 的终端交互界面。本模块直接服务于上层的输入解析层与渲染引擎，作为用户指令与底层系统交互的核心桥梁。

## 目录结构
```text
├── add-dir/ # 处理目录添加与加载的命令实现
├── agents/ # 多代理（Agent）协同相关的命令实现
├── init.ts # 初始化项目环境与生成 CLAUDE.md 的核心命令
├── ultraplan.tsx # 超级计划（Ultraplan）的交互式 JSX 终端组件命令
├── commit.ts # 提交流程与代码版本管理的命令实现
├── createMovedToPluginCommand.ts # 为迁移至插件的废弃命令生成拦截与引导提示的工厂函数
└── ... # 包含逾 90 个独立的命令子目录与脚本，每个文件与目录严格负责实现单一命令的功能闭环
```

## 实现逻辑分析
### 1. 命令接口规范
每个命令文件默认导出一个标准的命令配置对象或执行函数（遵循 `Command` 接口）。对于仅提供上下文的命令，实现 `getPromptForCommand` 以动态生成系统提示词；对于需要直接操作本地状态的命令，通过导出 `call` 函数触发系统级副作用（Side Effects）。

### 2. 终端富文本交互
针对复杂的工作流（以 `terminalSetup.tsx` 与 `ultraplan.tsx` 为例），命令使用 JSX 语法返回 `React.ReactNode`。这使得底层 Ink 渲染引擎能够渲染交互式进度条、多步提问与动态文本流，提升终端用户的交互体验。

### 3. 插件化降级机制
利用 `createMovedToPluginCommand.ts` 工厂函数，模块实现了对旧版本命令的无缝废弃与降级。当用户触发已迁移为独立插件的命令时，该机制会拦截原始执行流，输出静态的安装引导信息，在保障向后兼容性的同时推动功能插件化解耦。

## 新增 / 重构 / 删除向导
### 新增
1. 在当前目录下新建以命令名命名的文件（使用 `.ts` 或 `.tsx` 扩展名）或同名目录。
2. 实现并默认导出命令对象，确保包含唯一的 `name` 与描述性的 `description`。
3. 在外部主注册表中显式引入并挂载新添加的命令模块。
4. 补充相关的单元测试，覆盖正常交互逻辑与预期的异常中断分支。

### 重构
1. 保持暴露的执行函数签名（包含 `call` 与 `getPromptForCommand` 及其参数类型）的向后兼容。
2. 若重构涉及 JSX 组件，务必确保组件生命周期的正确挂载与卸载，避免终端渲染进程挂起。
3. 任何涉及本地环境提权或外部网络请求的执行逻辑必须保留安全失败（Fail-safe）约束，不得将其修改为故障敞口（Fail-open）策略。

### 删除
1. 确认已在历史版本中抛出废弃警告（Deprecation Warning）并符合标准下线周期要求。
2. 删除目标命令源码与关联测试文件，并彻底清理外部注册中心中指向该命令的显式引入。
3. 追溯并屏蔽所有上游调用方入口，强制移除该命令关联的静态快捷键映射。
