# src/memdir — 记忆目录模块

> 项目总览：参见 [README.md](../../README.md)
> 
> 相关模块：[`src/query/README.md`](../query/README.md)（依赖该模块过滤请求召回）

## 简介

本模块负责管理大模型长期记忆的持久化落盘与语义化检索。通过将记忆碎片序列化入硬盘并结合多级预过滤扫描机制，该模块提供了高效的知识召回通道。它是支撑智能助手跨会话连续性的核心本地知识库服务模块。

## 目录结构

```text
memdir/
├── findRelevantMemories.ts   # 基于大模型进行语义检索的筛选逻辑
├── memdir.ts                 # 记忆模块主入口，负责目录创建与读写流转
├── memoryAge.ts              # 时效性控制，针对过期记忆附加上下文警示
├── memoryScan.ts             # 高效扫描器，读取文件头获取元数据
├── memoryShapeTelemetry.ts   # 遥测埋点，追踪用户记忆体体积与形状
├── memoryTypes.ts            # 核心提示词与分类（如 feedback/project）枚举
├── paths.ts                  # 全局记忆目录的基本路径解析与构造
├── teamMemPaths.ts           # 包含深度防御逻辑的路径溯源与跨目录拦截
└── teamMemPrompts.ts         # 团队级记忆的专属组装与提示词构建
```

## 实现逻辑

### 1. 领域模型与数据分类 (`memoryTypes.ts`)
系统通过定义不同维度（如 `feedback` 和 `project`）组织记忆存储。通过构建带有 Frontmatter 的文件实体，并在全局 `MEMORY.md` 索引文件中写入指针，实现实体存储与检索索引的解耦。

### 2. 检索与召回链路 (`memoryScan.ts` & `findRelevantMemories.ts`)
- **异步浅层扫描**：扫描器仅提取 `.md` 文件头部若干行以截取元数据，保证性能不随文件数线性恶化。
- **模型辅助决策**：通过轻量级的语义任务，将扫描清单投递给模型，由其选出与当前轮次 Query 最贴合的记录，并剔除无效噪音。

### 3. 时效控制与安全防线 (`memoryAge.ts` & `teamMemPaths.ts`)
- **防过期毒化（Staleness Caveat）**：强制给过期的记忆打上风险补丁，警示调用方进行数据现势性核实。
- **目录逃逸拦截**：通过深层路径计算阻断所有包含符号链接穿透或恶意 URL 编码的读写操作。

## 新增 / 重构 / 删除向导

### 新增
- 扩充记忆种类时，必须在类型枚举中增加对应的模板映射。
- 若引入大规模数据遍历动作，必须优先采用非阻塞的异步处理方案。

### 重构
- 任何直接触发的写入操作，必须通过安全路径校验函数的审核。
- 严禁在负责 Prompt 拼装的主链路中使用同步文件系统调用避免造成阻塞雪崩。

### 删除
- 下线某类旧记忆分类时，必须补充降级转换逻辑以平滑兼容老用户硬盘内的残余文件。
- 确认阻断该逻辑涉及的所有上游外部入口触发点。
