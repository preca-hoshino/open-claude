# src/memdir — 记忆存储与检索引擎

> 项目总览：参见 [README.md](../../README.md)

## 简介

本模块负责管理大模型长期记忆的持久化存储、分类体系与语义化召回。核心机制包括基于本地文件系统与前置元数据（Frontmatter）的序列化，以及结合次级大模型调用的轻量级相关性筛选。本模块作为系统的本地知识库底座，支撑智能助手跨会话的数据连续性与团队上下文共享。

## 目录结构

```text
memdir/
├── findRelevantMemories.ts   # 执行基于大模型的语义检索与记忆相关性筛选
├── memdir.ts                 # 记忆目录主控制器，负责路径初始化与系统提示词（Prompt）注入
├── memoryAge.ts              # 处理记忆时效性计算，为过时内容提供上下文警告
├── memoryScan.ts             # 文件扫描器，提取 Markdown 头部元数据以生成清单
├── memoryShapeTelemetry.ts   # 收集并上报记忆体数据规模与查询命中率的遥测信息
├── memoryTypes.ts            # 定义四类记忆分类枚举并维护对应的提示词模板
├── paths.ts                  # 解析并管理持久化记忆目录的绝对路径与环境变量覆盖
├── teamMemPaths.ts           # 校验团队共享记忆路径，拦截路径穿透与符号链接逃逸攻击
└── teamMemPrompts.ts         # 拼接个人与团队混合模式下的专属系统提示词指导
```

## 实现逻辑

### 1. 记忆存储与分类体系
入口为主文件 `memoryTypes.ts`。本模块定义了四类长效记忆标签（用户偏好、反馈、项目上下文与外部引用），将实际记忆数据解耦为带有前置元数据的 Markdown 文件实体进行存储，并通过统一的入口文件维护当前目录下的文件链接，避免由于单文件无限膨胀导致解析超时。

### 2. 轻量级扫描与语义召回
核心实现在 `memoryScan.ts` 与 `findRelevantMemories.ts`。通过 `scanMemoryFiles` 函数异步提取目标目录内文件的头部 30 行，构建带有时间戳与描述信息的精简清单。该机制使用 `sideQuery` 构建独立模型会话，判定并选出至多 5 条与当前问题最为贴合的历史记录，从而降低主链路的检索开销。

### 3. 安全遏制与目录逃逸防御
核心机制位于 `teamMemPaths.ts`。通过 `validateTeamMemWritePath` 与 `validateTeamMemKey` 进行多级路径遏制检查。系统在操作团队内存路径前，强制执行真实路径解析（Realpath Resolution）和前缀包含匹配，以此防范任何通过点号相对路径跳跃（Path Traversal）或畸形符号链接（Symlink）发起的访问越权攻击。

### 4. 动态上下文提示与时效性警示
位于 `memdir.ts` 与 `memoryAge.ts`。依据当前启用的个人内存与团队内存开关组装完整的系统提示词片段，告知主模型如何读取和修改记忆文件。针对修改时间较早的数据文件，系统会在最终投递前强行插入安全提醒（System Reminder），强制模型在认定该信息为事实前先进行二次核验，防止产生时效性幻觉。

## 新增 / 重构 / 删除向导

### 新增
- 扩展长效记忆分类时，必须在 `MEMORY_TYPES` 枚举中注册对应标识，并在 `TYPES_SECTION_INDIVIDUAL` 与 `TYPES_SECTION_COMBINED` 集合中补充匹配的适用范例。
- 引入新的数据遍历动作时，必须采用异步文件系统调用（Asynchronous I/O），杜绝阻塞主线程流转。

### 重构
- 调整目录计算函数与路径构建逻辑时，必须保留防穿透校验机制，确保任何输入均受到安全遏制（Containment Check）。
- 修改路径扫描机制时，若涉及权限隔离，必须显式捕获无权限异常并执行安全失败（Fail-safe）回退策略。

### 删除
- 下线某一具体记忆标签前，必须部署降级兼容转换策略以支持老版本遗留数据的平滑解析。
- 废除核心检索接口时，必须彻底追溯并移除上游关联模块的全部调用链入口。
