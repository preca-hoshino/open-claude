# src/native-ts — 跨平台原生依赖的 TypeScript 移植层

> 参见 [README.md](../../README.md)
> 关联模块：[src/components](../components) 消费差异化着色功能，[src/hooks](../hooks) 调用文件级模糊搜索索引，[src/ink](../ink) 依托本层的 Flexbox 计算布局。

## 简介

本模块提供核心计算库的纯粹 TypeScript 移植实现，主要职责是剥离跨平台部署时对 C++ 甚至 Rust 原生二进制附加组件的编译依赖。依靠重写差异着色、路径检索引擎和界面布局核心机制，本模块向上提供兼容且轻量的应用级接口。本模块作为系统的底层计算基础设施，专门支撑前端用户界面的流畅渲染与交互响应。

## 目录结构

```text
├── color-diff/
│   └── index.ts        # 提供终端环境下的语法高亮与词组级别文本差异着色计算
├── file-index/
│   └── index.ts        # 构建基于内存的高性能文件模糊搜索树，包含异步分块打分算法
└── yoga-layout/
    ├── enums.ts        # 定义界面排版约束所需的核心枚举类型常量
    └── index.ts        # 裁剪并复刻 Flexbox 排版引擎子集，推算组件最终渲染物理坐标
```

## 实现逻辑

### 1. 终端差异化着色 (Color Diff)

以 `color-diff/index.ts` 为主脑，基于开源词法解析器和序列对比算法实现了终端呈现层面的语法着色与词汇级别变更对比。特别采用懒加载机制（Lazy-loading）推迟全量内置语言语法的注册操作，直接规避程序冷启动时因全量语法解析带来的堆内存浪涌和垃圾回收停顿（GC-pause）。同时通过自定义渲染管线将匹配树直接转换为终端专用的 ANSI 转义字符序列输出。

### 2. 模糊搜索索引 (File Index)

以 `file-index/index.ts` 中的 `FileIndex` 类为核心，构建了专用于匹配文件路径的高频模糊搜索引擎。读取全项目路径列表时严格应用时间分块让权（Time-based chunking）机制执行内存加载，保证超大规模树状结构遍历操作绝对不阻塞底层事件循环（Event loop）。检索搜索时引入预计算字符位图（Precomputed bitmap）急速筛除未命中项目，最后结合匹配字符间隙惩罚（Gap penalty）和连续命中奖励完成高精度的相关度排位积分映射。

### 3. Flexbox 布局引擎 (Yoga Layout)

依靠 `yoga-layout/index.ts`，专门适配终端界面的控制台网格排布特性，打造出一套单阶段布局算法（Single-pass flexbox implementation）。剔除无关冗余浏览器层特性的同时，完整保留并复刻绝对定位边界、主轴侧轴自适应伸缩、物理边距留白和弹性换行断行规则。系统内部集成了双层脏节点标记布局缓存（Dirty-flag layout cache）应对深度嵌套组件层级结构里的递归测量（Recursive measure）重复计算开销，以此将全局终端渲染帧生成时间压缩至微秒级区间。

## 新增 / 重构 / 删除向导

### 新增
- 引入纯逻辑模块替代方案时，创建专属隔离特性子目录，并同步维护本层的对外公用接口命名签名严格一致。
- 确保新加入的移植层代码完全切断对于操作系统宿主底层原生环境编译链的依赖，并补充覆盖边界验证场景路径的自动化测试脚本。

### 重构
- 调优内部语法解析与搜索打分核心算法时，维持面向终端应用侧导出的全局公有方法对象签名绝对向后兼容。
- 更改大文件目录读取的异步任务调度协程时，坚守预设时间切片释放系统资源的临界边界，严防长时死循环独占锁死外部用户键盘终端事件侦听。
- 本模块内置高亮渲染引擎附带一套针对无法精准探测编程语言格式的安全失败（Fail-safe）后备容灾策略，迭代修改底层匹配规则时必须保留拦截底层解析抛错异常并直接降级输出原始纯文本的异常处理机制，杜绝渲染主进程因此触发未捕获错误导致整体退出。

### 删除
- 下达清退过期原生垫片模块指令前，必须执行全局代码库反向索引操作并彻底屏蔽所有引用的上游控制流组件逻辑和挂载操作调用路径。
- 删除该特定模块的独立包路径代码文件夹及其暴露类型定义描述档，并且最后在此说明文档目录章节中执行彻底结构删减。
