# src/state — 全局应用状态管理模块

> 项目总览：参见 [README.md](../../README.md)
> 
> 相关模块：[`src/remote/README.md`](../remote/README.md)（接收状态并同步远端）

## 简介

本模块提供了一个响应式、类型安全的全局状态管理层，支撑应用中的高频复杂状态流转。通过融合纯函数订阅发布机制与 React 并发特性，该模块在确保极致渲染性能的同时实现了视图与数据的彻底解耦，是所有应用视图的根基设施层。

## 目录结构

```text
state/
├── AppState.tsx             # 状态容器的 React 上下文提供者及消费 Hook
├── AppStateStore.ts         # 定义全局状态的数据树结构及默认值初始化
├── onChangeAppState.ts      # 拦截器，监听特定状态变化以触发关联的副作用
├── selectors.ts             # 纯函数选择器，提供无副作用的组合式读取推导
├── store.ts                 # 闭包实现的微型高效 Vanilla JS Store
└── teammateViewHelpers.ts   # 封装子代理状态流转与视图垃圾清理的硬逻辑
```

## 实现逻辑

### 1. 轻量级状态容器 (`store.ts` & `AppStateStore.ts`)
采用自行实现的高效纯 JavaScript Store，规避了重量级状态库开销。
- **不可变更新**：详尽定义状态树，要求每次修改都必须遵循完全的不可变更新（Immutable Updates）原则。
- **安全自举**：针对多样的运行环境（如是否启用子代理编排）进行惰性推断默认值。

### 2. 局部订阅与级联 (`AppState.tsx`)
将底层 Store 与 UI 绑定，杜绝雪崩式重绘。
- **外部同步驱动**：依赖 `useSyncExternalStore`，允许组件通过选择器挂载状态切片，仅当涉及的局部树状数据变化时方触发渲染。

### 3. 状态监听与副作用分流 (`onChangeAppState.ts`)
负责对状态树的变化路径进行监听并产生副作用。
- **配置持久化**：深度比对新旧状态，并在视图控制或权限阈值变动时同步落盘。
- **越权与缓存剥离**：拦截密钥凭证更新等敏感操作，并在生效时立即驱逐内存缓存强制重载。

### 4. 派生聚合逻辑 (`selectors.ts` & `teammateViewHelpers.ts`)
提供基于业务语义组合出的无污染推导视图（如通过活动标识获取当前响应目标），并妥善管理生命周期对象的滞留（Retain）策略。

## 新增 / 重构 / 删除向导

### 新增
- 需在状态树定义中加入强类型约束的字段，并赋予明确的默认初值。
- 若新状态具有持续影响力，在拦截器文件中注册变更监听器。

### 重构
- 严禁在选择器（Selector）内部执行 `.map()` 或返回新的字面量对象，这会击穿比对造成渲染死循环。
- UI 渲染过程中严禁直接抛出具有副作用的阻塞操作。

### 删除
- 彻底清理在组件树中使用被弃用切片选择器的勾子。
- 确认移除在监听器网络中相关联的所有后置清理与副作用执行环节。
