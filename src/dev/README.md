# src/dev — 开发环境专属模块

> 项目总览：参见 [README.md](../../README.md)
> 
> 相关模块：[`src/cli/README.md`](../cli/README.md)（命令行入口）

## 简介

Dev 模块主要包含了仅用于开发、调试、或是沙盒测试过程的逻辑。例如用于注入运行时的全局变量（globals）以绕过部分正式环境的安全限制和监控。该模块不会且不应该在正式打包后被执行。

## 目录结构

```text
dev/
├── installRuntimeGlobals.ts         # 运行时全局变量或特权代理注入
└── __test__/                        # 测试目录
    └── ...
```

## 实现逻辑

### 运行时全局注入
`installRuntimeGlobals.ts` 劫持或替换了某些核心模块的默认行为。在开发态时被激活，用于暴露出隐藏的调试端点、代理钩子或测试桩，以加速排障。

### 隔离防御机制
通过环境变量或显式的启动标志保护该模块的加载链路，确保这些极具破坏性和不安全的变量注入永远不会进入生产环境的运行时状态。

## 新增 / 重构 / 删除向导

### 新增
- 引入新的调试辅助方法时，务必加上 `// @ts-ignore` 等声明规避严格检查，并将其包裹在明确的 `isDev` 条件分支中。

### 重构
- 请勿在此模块中引用生产环境的核心业务接口，以避免由于逆向依赖导致构建包体积膨胀或安全漏洞。

### 删除
- 如果某个调试探针已废弃，可直接移除代码和调用侧的 `import`，无明显副作用。
